# AI-Powered Client Management Automation

## Overview

This project demonstrates an AI-powered workflow automation system built using n8n, Google Gemini AI, Telegram Bot, Google Sheets, and Gmail.

The system automates client data management, intelligent querying, and communication workflows.

---

## Business Problem

Managing client payment records, answering queries, and sending reminders manually can be time-consuming and error-prone.

This solution automates these tasks using AI and workflow automation.

---

## Features

- Real-time Telegram Bot interaction
- Natural language querying using Gemini AI
- Google Sheets as a dynamic database
- Automated Gmail notifications
- Workflow orchestration using n8n
- Real-time data synchronization

---
